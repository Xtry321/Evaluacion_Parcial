# Evaluacion Parcial

Aplicacion web para gestion de usuarios, examenes y certificaciones. Construida con React + TypeScript y Vite, con persistencia local en LocalStorage.

## Requisitos

- Node.js 18+ (recomendado)

## Instalacion

```bash
npm install
```

## Comandos utiles

```bash
# desarrollo
npm run dev

# build de produccion
npm run build

# vista previa del build
npm run preview
```

## Estructura principal

- src/router: rutas y proteccion de vistas
- src/contexts: estado global (auth, examenes, certificados)
- src/components: UI y formularios
- src/services: acceso a LocalStorage
- src/pages: pantallas principales
